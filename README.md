# 行前夹 TripClip — 使用说明

> **当前版本：v0.3** · 更新于 2026-08-19

**一个帮助"手动攻略型"自由行用户在出行前收集、整理、整合旅行资料的本地 Web 工具。**

纯前端单页应用，无后端、无依赖、无账号。数据保存在浏览器本地（localStorage），打开即用。

## 快速开始

直接双击 `index.html` 用浏览器打开，或用任意静态服务器托管：

```bash
cd tripclip
python3 -m http.server 8123
# 访问 http://localhost:8123
```

## 核心功能

| 功能 | 说明 |
|---|---|
| ✨ 智能提取 | 粘贴小红书链接 + 帖子正文，自动提取店名/地址/营业时间/人均/备注 |
| 🗺 地图跳转 | 每条记录一键跳转 Google Maps（按名称+地址搜索） |
| 🔗 原文回跳 | 保留小红书原链接，可回到原文 |
| ✈️ 行程录入 | 类型快捷选择（机票/火车/酒店/门票/餐厅/景点），字段按类型联动：航班号、起飞时间、出发→到达、车次、入住退房、订单号等 |
| 🔄 免费退订 | 酒店/机票/门票可记「免费退订截止」，卡片绿色高亮显示，一眼看到取消底线 |
| 📋 地址复制 | 卡片上点地址或"📋 复制"按钮，一键复制到剪贴板 |
| 🏷 类型/标签筛选 | 顶部类型 chips 按机票/火车/酒店等分类查看；标签按区域/日期筛选 |
| ＋ 手动录入 | 酒店、机票等非小红书来源信息手动录入 |
| 💾 本地持久化 | localStorage 存储，关页面数据不丢 |
| 📤 导出 | 一键导出 Markdown / CSV（Notion 可导入），含行程时间/车次/订单号字段 |

## 行程录入字段说明

选择类型后，日期时间/编号/出发到达/订单备注四个字段的提示会自动切换：

| 类型 | 时间字段 | 编号字段 | 出发→到达 | 订单/备注 | 免费退订 |
|---|---|---|---|---|---|
| ✈️ 机票 | 起飞时间 | 航班号 | 出发地 → 目的地 | 订单号 / 座位号 | 免费退改截止 |
| 🚄 火车 | 发车时间 | 车次 | 出发站 → 到达站 | 座位号 / 订单号 | 免费退改截止 |
| 🏨 酒店 | 入住 — 退房 | 酒店电话 | 房型 | 订单号 / 确认号 | 免费退订截止 |
| 🎫 门票 | 使用日期 | 票号 | 场馆 / 地点 | 订单号 / 入场信息 | 免费退订截止 |
| 🍜 餐厅 | 预约时间 | 电话 | 位置 | 推荐菜 | 取消政策 |
| ⛰️ 景点 | 开放 / 预约时间 | 票价 | 区域 | 注意事项 | 退订 / 取消说明 |

## 提取规则（支持格式）

- `店名：` `名称：` `【店名】` 或 `XX店 打卡！`
- `地址：` `📍 地址` / 自由文本中的省市路街
- `营业时间：` `🕐` `9:30-17:00` `周一闭馆`
- `人均：` `💰` `人均 3000円`
- `推荐/必点/Tips` 开头的行 → 备注

提取结果可随时编辑修正。

## 已知边界

- **不做真实的小红书内容爬取**（跨域 + 反爬 + 合规），采用"粘贴链接 + 粘贴正文"方案实现等价价值
- 营业时间提取自帖子，可能过时，出行前建议以 Google Maps 为准（字段上"待确认"标记）
- 数据仅存本机浏览器；清除浏览器数据会丢失，建议定期导出 Markdown/CSV 备份
