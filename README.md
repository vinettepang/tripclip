# 行前夹 TripClip — 使用说明

> **当前版本：v0.6.8** · 更新于 2026-08-20

**一个帮助"手动攻略型"自由行用户在出行前收集、整理、整合旅行资料的 Web 工具。**

纯前端单页应用 + 可选云同步。**不登录** = 纯本地模式（数据存浏览器 localStorage，打开即用）；**登录账号** = Mac / 手机数据自动同步（数据存 Supabase 云数据库 + 本机缓存双保险）。

## 快速开始

直接双击 `index.html` 用浏览器打开，或用任意静态服务器托管：

```bash
cd tripclip
python3 -m http.server 8123
# 访问 http://localhost:8123
```

## 核心功能

| 功能 | 说明 |
|---|---|
| ✨ 智能提取 | 粘贴小红书链接 + 帖子正文，自动提取店名/地址/营业时间/人均/备注 |
| 🗺 地图跳转 | 每条记录一键跳转 Google Maps（按名称+地址搜索） |
| 🔗 原文回跳 | 保留小红书原链接，可回到原文 |
| ✈️ 行程录入 | 类型快捷选择（机票/火车/酒店/门票/餐厅/景点），字段按类型联动：航班号、起飞时间、出发→到达、车次、入住退房、订单号等 |
| 🔄 免费退订 | 酒店/机票/门票可记「免费退订截止」，卡片绿色高亮显示，一眼看到取消底线 |
| 📋 地址复制 | 卡片上点地址或"📋 复制"按钮，一键复制到剪贴板 |
| 🧬 复制条目 | 一键复制某条收藏生成副本（名称带"（副本）"），自动打开编辑弹窗，改完即存，适合同店多晚、同行程多日等场景 |
| 🗑 删除条目 | 卡片上一键删除（有确认提示防误删）；编辑弹窗内也可删除 |
| 🏷 类型/标签筛选 | 顶部类型 chips 按机票/火车/酒店等分类查看；标签按区域/日期筛选 |
| ＋ 手动录入 | 酒店、机票等非小红书来源信息手动录入 |
| ☁️ 云同步 | 邮箱密码账号，登录后 Mac / 手机数据自动同步；首次登录可一键迁移本机数据到云端；断网时改动自动排队，联网后点「重新同步」重试 |
| 💾 本地持久化 | localStorage 存储，关页面数据不丢；登录后云端 + 本机双份 |
| 📤 导出 | 一键导出 Markdown / CSV（Notion 可导入），含行程时间/车次/订单号字段 |

## 行程录入字段说明

选择类型后，日期时间/编号/出发到达/订单备注四个字段的提示会自动切换：

| 类型 | 时间字段 | 编号字段 | 出发→到达 | 订单/备注 | 免费退订 |
|---|---|---|---|---|---|
| ✈️ 机票 | 起飞时间 | 航班号 | 出发地 → 目的地 | 订单号 / 座位号 | 免费退改截止 |
| 🚄 火车 | 发车时间 | 车次 | 出发站 → 到达站 | 座位号 / 订单号 | 免费退改截止 |
| 🏨 酒店 | 入住 — 退房 | 酒店电话 | 房型 | 订单号 / 确认号 | 免费退订截止 |
| 🎫 门票 | 使用日期 | 票号 | 场馆 / 地点 | 订单号 / 入场信息 | 免费退订截止 |
| 🍜 餐厅 | 预约时间 | 电话 | 位置 | 推荐菜 | 取消政策 |
| ⛰️ 景点 | 开放 / 预约时间 | 票价 | 区域 | 注意事项 | 退订 / 取消说明 |

## 提取规则（支持格式）

**使用方式**：小红书 App 点「分享」→ 粘贴到输入框，链接和正文自动拆分提取。

- 链接自动提取：`xiaohongshu.com/explore/xxx`、`xhslink.com/xxx`、任意 URL
- 推广尾部自动清除：「复制此信息…」「🔗 URL」行
- `店名：` `名称：` `【店名】` 或 `XX店 打卡！`
- 竖线标题：`东京必吃｜一兰拉面` → 取后半段作名称
- `地址：` `📍 地址` / 自由文本中的省市路街 / 日文地址（都府县町）
- `营业时间：` `🕐` `9:30-17:00` `周一闭馆`
- `人均：` `💰 人均¥120` `💰 ¥120`
- `推荐/必点/Tips/特色/招牌` 开头的行 → 备注
- hashtag 行（`#美食`）不干扰名称提取

提取结果可随时编辑修正。

## 文件

- `index.html` — 应用本体（单文件，含全部样式与逻辑，当前正式版 v0.6.8）
- `vendor/supabase.min.js` — Supabase JS SDK（本地化，不依赖外部 CDN）
- `supabase-schema.sql` — 云数据库结构（建表 + 行级安全策略，Supabase SQL Editor 里跑一次）
- `SETUP.md` — 云同步配置手册（自建 Supabase 项目时使用；**开箱版已内置默认配置，无需任何设置**）
- `.github/workflows/deploy.yml` — GitHub Pages 自动部署（push main 自动发布）
- `PUBLISH.md` — 发布到 GitHub Pages 的手动操作手册
- `index.v0.4.html` — 含 Notion 同步功能的完整代码（**二期资产**，暂不启用）
- `worker.js` — Notion 同步中转服务（Cloudflare Worker 部署代码，**二期资产**）
- `DEPLOY.md` — Notion 同步部署指南（二期启用时使用）
- `travel-clip-prd.md` — 产品规格文档

## 已知边界

- **不做真实的小红书内容爬取**（跨域 + 反爬 + 合规），采用"粘贴链接 + 粘贴正文"方案实现等价价值
- 营业时间提取自帖子，可能过时，出行前建议以 Google Maps 为准（字段上"待确认"标记）
- 不登录时数据仅存本机浏览器，清除浏览器数据会丢失；建议登录账号（云端备份）或定期导出 Markdown/CSV
- 云同步依赖 Supabase 服务可用；项目区域建议选新加坡/东京（国内访问更稳）
